# RA16-F5-GLP-SCORE4: selective four-block Score lifecycle

**Status:** **Functional PASS** for the official 384x640 continuous Full5 contract.
Timing is a single diagnostic-instrumented observation; formal repeated timing is
**Not Run**.

## Question and frozen contract

The parent `RA16-F5-GLP-OFFLOAD` removed the inactive Generator ZeRO-1 BF16
flat state and reduced Critic pre-backward allocation by exactly 2.330994 GiB,
but resident Score still OOMed during Critic checkpoint recomputation. This
bounded experiment changed one policy only: stream Score frozen blocks
`[36, 37, 38, 39]` with window 1.

Everything else remained frozen: 2x8 A100-40GB, official 384x640, MB1/GAS1,
global batch 16, rank-qualified trace v3, immutable checkpoint-10, steps
10--14, ZeRO-1 CPU optimizer, Generator `g12`, typed Generator LP-state phase
offload, A32 Generator/Critic activation offload, one Generator update, five
Critic updates and five EMA updates.

The safe implementation does not delete arbitrary parameters in the middle of
autograd. These four immutable Score blocks remain CPU/shared-backed outside a
physical block call, materialize before forward or checkpoint-recompute use,
and release after CUDA use completes. During Critic backward this bounds the
four-block set to one resident block while preserving all recomputation math.

reserved. Sampled cgroup peaks were 737,171,681,280 B on node 0 and

and no CUDA OOM signature.

## Correctness result

All 16 ranks completed steps 10--14. Observed state transitions were exact:

- Generator: `G2 -> G3`, exactly one optimizer update at step 10;
- Critic: `C10 -> C15`, five ordered optimizer updates;
- sparse EMA: `EMA10 -> EMA15`, five updates with the recorded predicates;
- both activation-offload scopes (`generator_selected`, `critic_train`) ended
  with zero live CPU bytes;
- Generator and Score streamers both ended with zero resident bytes;
- checkpoint-15 passed structural validation: 97 files, 99,826,069,878 B,
  digest `7ac25628909407517edd4e7c2178c0e69c9b8d2d2eafb2d1840e5fdd07e88d19`.

The first summarizer artifact is deliberately preserved. It reported FAIL only
because its validator hard-coded exactly one `activation_offload_final` record;
the run correctly emitted two installed/final component scopes, both with zero
live bytes. Summarizer v2 matches installed and final component multisets and
still requires every final live-byte value to be zero. Re-analysis of the same
immutable traces produced PASS with zero evidence errors; no model run was
retried and no numerical or semantic threshold was relaxed.

## Interpretation and boundary

The preregistered hypothesis is verified: with Generator `g12`, typed Generator
LP-state phase offload and unchanged activation policy, selectively streaming
four Score tail blocks is sufficient to turn the parent Critic-backward OOM
into a complete official Full5 run. The result does **not** prove that four is
the minimum; no 1/2/3-block sweep was authorized. It also does not transfer to
the split-role Pipeline executor, whose physical state inventory differs.

No further block sweep or formal timing was launched. The next defensible step,
if authorized, is repeated paired timing of this frozen Score4 plan against the
same-contract strongest all-40 Route-A baseline.
