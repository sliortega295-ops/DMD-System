# Frozen contract: RA16-F5-PR12

`RA16-F5-PR12` is a separately authorized, one-attempt successor to the failed
`RA16-F5-PR8` admission test. It does not modify or erase PR8.

## Frozen workload

- two nodes, 16 ranks, one complete Route-A flow per rank;
- official 384x640, latent `[1,16,9,48,80]`, BF16;
- rank16 operation trace v3 and checkpoint-10;
- continuous steps 10--14;
- ZeRO-1 with CPU optimizer offload, MB1/GAS1/global batch 16;
- one Generator update, five Critic updates and five EMA updates;
- `G2/C10/EMA10 -> G3/C15/EMA15`;
- default no-GAN/no-Reward/no-VAE Stage-3 branch.

## Only lifecycle change from PR8

Step10-A Generator uses window-1 frozen-block streaming for exactly:

```text
[0,24,1,5,8,25,10,32,36,15,16,26]
```

The first eight indices are frozen PR8 order; the four additions are the next
entries in the preregistered isolated g40 pressure order. Score remains without
a block streamer. Critic-only Generator rollouts retain these blocks only for
the complete rollout phase. Activation offload remains unchanged at 32 MiB for
`generator_selected` and `critic_train`; no allocator-cache recovery, prefetch,
shape, trace, batch, optimizer, EMA or update-order change is allowed.

## Attempt and gates

Exactly one functional attempt is allowed. It passes only if all 16 ranks replay
the exact trace, complete steps 10--14 and checkpoint-15, reach
`G3/C15/EMA15`, stream only the twelve declared Generator blocks, emit no Score
block-stream events, finish with balanced lifecycle handles, and add no CUDA or
cgroup OOM.

A failure at any earlier gate refutes this candidate. Formal repeated timing is
`Not Run` regardless of the one functional result. Existing low-overhead events
may be analyzed per rank, but unclassified memory cannot be labelled redundant.
