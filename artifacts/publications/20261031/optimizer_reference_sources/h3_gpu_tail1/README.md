# H3 block49 output-cache historical source snapshot

These two files preserve the exact bytes of local experiment commit
`45938af88d65ddb15b96ec1a181b65aa4e92de70`. That commit was not published to
GitHub; the optimizer library therefore links to this public archive instead.
`origin.json` records the original paths and SHA-256 values.

This is source navigation for the historical W6 GPU-tail1 output-storage
experiment. It is not parameter residency or a standalone reusable package.
The module depends on its original versioned native cache helpers, consumer
order and training integration. The test file also expects those helpers and
an explicit environment-specific helper root. Do not run it as a current
acceptance check without reconstructing and validating those dependencies.

No archived source was changed, imported, or executed for this publication.
No component/GPU test or historical timing was repeated. Existing DMD-System
license and source attribution apply.
